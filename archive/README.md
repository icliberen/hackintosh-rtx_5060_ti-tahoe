# Historical helper source, for review

These redacted `.txt` files preserve helper source from the local experiment, including failed candidates. They are not executable deliverables or a universal installer. Do not rename and run them unchanged. Some paths and UUIDs are deliberately replaced with invalid placeholders, and scripts assume exact original package/probe hashes.

The selected originals, original logs and full file inventory remain local. The failed loginwindow and SetupVirtualMap experiments are retained to explain what did not solve the problem. The source tree for the base driver is obtained from upstream, not reconstructed from these helpers.
